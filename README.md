# ATU Smart Parking

[Онлайн сайтты ашу](https://aitbaev1ernur.github.io/atu-smart-parking/)

Сайран кампусы маңындағы жол бойы тұрақтарының демо картасы.

- Қолданушы: `user` / `demo123`. Бір орынды брондап, броньды болдырмай алады. A аймағы тегін, B аймағы 300 ₸/бронь (демо төлем).
- Әкімші: `admin` / `admin123`. Тұрақ күйін өзгертіп, бастапқы күйді қалпына келтіре алады.
- Демо күй осы браузерде сақталады. Карта дерегі — OpenStreetMap қатысушылары (ODbL).
- Интернетсіз ашу үшін `docs/atu-parking-offline.html` файлын браузерде ашыңыз.

GitHub Pages жариялау көзі — `main` тармағындағы `/docs` бумасы.
